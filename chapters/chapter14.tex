\chapter{Conclusion and Future Work}
This thesis has presented a comprehensive approach to the lightweight semantic structuring of internship listings, addressing the challenges of high-volume, noisy recruitment data. By combining traditional rule-based extraction with modern, small-scale Transformer models, we have demonstrated that it is possible to build a robust and efficient knowledge base without the excessive costs and latency of large-scale LLM dependencies, following the trend towards more sustainable and efficient AI \cite{schwartz2020green, menghani2023efficient}.

\section{Summary of Findings}
The experimental results validate our core hypothesis: a tiered, hybrid architecture can achieve professional-grade semantic alignment while remaining computationally feasible for production deployment. Our key findings include:

\begin{itemize}
    \item \textbf{Efficiency and Scalability:} The system achieved an ingestion throughput suitable for real-time updates on commodity hardware, confirming that semantic search can be delivered with the responsiveness required for interactive applications \cite{buttcher2016information, johnson2019billion}.
    \item \textbf{Extraction Accuracy:} Deterministic fields were extracted with high precision, while semantic mapping of job roles achieved high Top-3 accuracy using lightweight bi-encoders, bridging the gap between raw text and standardized taxonomies like ESCO \cite{esco2017handbook, reimers2019sentence}.
    \item \textbf{Search Relevance:} The hybrid retrieval strategy outperformed keyword-only search, effectively addressing the "semantic gap" for conceptual queries in the recruitment domain \cite{thakur2021beir, luan2021sparse}.
    \item \textbf{Operational Cost:} By utilizing local models for the vast majority of processing, the system reduces reliance on expensive external APIs, adhering to principles of Knowledge Distillation and efficient inference \cite{hsieh2023distilling, menghani2023efficient}.
\end{itemize}

\section{Future Directions}
While the current system provides a solid foundation for internship analytics, several areas remain for future exploration and improvement \cite{tamburri2020data, lacic2020recommender}.

\subsection{Multilingual Extraction}
A primary limitation is the current focus on English-language listings. Expanding the pipeline to support multilingual extraction using cross-lingual models would be essential for a truly global internship platform, leveraging the multilingual definitions in the ESCO framework \cite{esco2017handbook, lin2021pretrained}.

\subsection{Better Section Segmentation}
Future work could employ more sophisticated models to explicitly segment job postings into structured blocks like "Responsibilities" and "Benefits". This would allow for more granular skill weighting and better context-aware matching \cite{qin2018enhancing, bhola2020retrieving}.

\subsection{Self-training and Distillation}
We envision a continuous self-training loop where high-confidence labels generated by larger models are used to periodically fine-tune local models. This distillation process would allow the lightweight components to gradually improve without inheriting high latency \cite{hsieh2023distilling, sanh2019distilbert}.

\subsection{Continuous Monitoring for Taxonomy Drift}
The technical landscape is in constant flux, with new frameworks and job roles emerging frequently. Implementing automated "drift detection" would allow the system's semantic schema to stay up-to-date with minimal manual effort, addressing the challenges of ontology evolution in the labor market \cite{shvaiko2013ontology, staab2009handbook}.
