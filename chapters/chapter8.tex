\chapter{Lightweight Semantic Enrichment Pipeline}
The semantic enrichment pipeline is the computational heart of the system, responsible for transforming raw, unstructured text into the structured format defined in Chapter 7. To meet the goals of high performance and low maintenance, we implement a refined, rule-based extraction engine using TypeScript, focusing on deterministic patterns and lexical matching.

\section{Regex-Based Attribute Extraction}
A significant portion of critical internship metadata follows semi-structured patterns that are highly suitable for Regular Expression (Regex) extraction.

\subsection{Standardized Salary Parsing}
The \texttt{cleanSalary} function utilizes regex to identify and normalize compensation information.
\begin{itemize}
    \item \textbf{Range Detection:} The system looks for patterns like \texttt{\$[\textbackslash d\textbackslash .,]+[KMB]?\textbackslash s*[–-]\textbackslash s*\$[\textbackslash d\textbackslash .,]+}.
    \item \textbf{Single Value Extraction:} If a range is not found, it falls back to capturing single currency mentions (e.g., "\$25/hr").
    \item \textbf{Normalization:} Extracted strings are trimmed and standardized to a canonical display format, or marked as "Salary not specified" to ensure UI consistency.
\end{itemize}

\subsection{Stable Identifier Generation}
To ensure referential integrity across the system (e.g., for bookmarked roles), we implement a deterministic \texttt{generateId} algorithm. This function transforms the \texttt{title} and \texttt{company} into a URL-friendly slug by:
\begin{enumerate}
    \item Converting text to lowercase.
    \item Removing non-alphanumeric characters.
    \item Replacing whitespace and multiple dashes with single hyphens.
    \item Trimming leading/trailing hyphens.
\end{enumerate}
This ensures that the same internship from different ingestion cycles always maps to the same internal ID.

\section{Lexical Skill Extraction}
The extraction of technical competencies is performed through the \texttt{extractSkills} module, which implements a high-performance keyword matching strategy.

\begin{itemize}
    \item \textbf{Lexicon-Based Matching:} The system maintains a target lexicon of over 40 industry-standard technical keywords (e.g., "React", "Python", "Kubernetes", "Data Analysis").
    \item \textbf{Case-Insensitive Scanning:} The cleaned job description is scanned for the presence of these keywords.
    \item \textbf{Density Control:} To prevent "keyword stuffing" and maintain focus, the system selects and capitalizes the first 5 unique matches found in the text.
\end{itemize}
