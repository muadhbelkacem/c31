\chapter{Methodology and System Overview}
This chapter provides the architectural blueprint for the lightweight semantic structuring system. By leveraging the Next.js App Router and a modular TypeScript backend, the system achieves a performant data pipeline that avoids the latency of external LLM dependencies while maintaining high extraction precision.

\section{The Ingestion Pipeline}
The data ingestion process, implemented in \texttt{app/lib/data.ts} and mirrored in the API layer, follows a sequence of operations to ensure raw JSON data is transformed into structured entities.

\begin{enumerate}
    \item \textbf{I/O and Safety Validation:} The system reads \texttt{intern\_data.json} using \texttt{promises/fs}. It performs safety checks to ensure the file is not empty and does not contain unexpected HTML error responses (common in proxy-based scraping).
    \item \textbf{Cleaning and Normalization:}
        \begin{itemize}
            \item \textbf{Text Fields:} Uses \texttt{cleanTitle}, \texttt{cleanCompany}, and \texttt{cleanLocation} to handle missing values and whitespace.
            \item \textbf{Salaries:} Employs the regex \texttt{/\$[\textbackslash d\textbackslash .,]+[KMB]?\textbackslash s*[–-]\textbackslash s*\$[\textbackslash d\textbackslash .,]+[KMB]?(?:\textbackslash /[a-z]+)?/i} to isolate compensation values from noisy text.
        \end{itemize}
    \item \textbf{ID Generation and Conflict Resolution:} The \texttt{generateId} function creates slugs. If multiple listings share the same title and company, a sequential suffix is appended to ensure uniqueness.
    \item \textbf{Semantic Mapping:}
        \begin{itemize}
            \item \textbf{Skills:} Case-insensitive matching against a dictionary of technical keywords.
            \item \textbf{Categories:} Heuristics mapping roles to domains such as \textit{Software}, \textit{Data/AI}, or \textit{Healthcare}.
        \end{itemize}
    \item \textbf{State Management:} Processed results are stored in a \texttt{cachedInternships} variable with a 300,000ms (5-minute) TTL to optimize server response times.
\end{enumerate}
