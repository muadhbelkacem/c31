\chapter{Methodology and System Overview}
This chapter provides the architectural blueprint for the lightweight semantic structuring system. By leveraging the Next.js App Router and a modular TypeScript backend, the system achieves a performant data pipeline that avoids the latency of external LLM dependencies while maintaining high extraction precision.

\section{Core Data Model}
The semantic integrity of the pipeline is maintained by the \texttt{Internship} interface defined in \texttt{app/lib/data.ts}. This model acts as the "Contract" between the ingestion scripts and the frontend presentation layer, ensuring that all extracted entities adhere to a strict schema.

            \texttt{company: string} \hfill \textit{// Normalized company name} \\

\section{The Ingestion Pipeline}
The data ingestion process, defined in \texttt{app/lib/data.ts}, follows a strictly sequential pipeline to ensure that messy web-scraped data is transformed into high-quality semantic entities.

\begin{enumerate}
    \item \textbf{I/O and Parsing:} The system reads \texttt{intern\_data.json} using the Node.js \texttt{promises/fs} module. It validates that the content is a valid JSON array and not an HTML error page or empty file.
    \item \textbf{Cleaning and Normalization:}
        \begin{itemize}
            \item \textbf{Titles:} Truncates noise and provides "Position Not Specified" fallbacks.
            \item \textbf{Salaries:} Uses the regex \texttt{/\$[\textbackslash d\textbackslash .,]+[KMB]?\textbackslash s*[–-]\textbackslash s*\$[\textbackslash d\textbackslash .,]+[KMB]?(?:\textbackslash /[a-z]+)?/i} to extract compensation ranges.
        \end{itemize}
    \item \textbf{Deterministic ID Generation:} Slugs are created by combining the title and company (e.g., \texttt{software-engineer-google}). Collisions are handled by appending a sequential counter (\texttt{-1}, \texttt{-2}).
    \item \textbf{Semantic Mapping:}
        \begin{itemize}
            \item \textbf{Skills:} Case-insensitive matching against a 40+ keyword lexicon (JavaScript, Python, AWS, etc.).
            \item \textbf{Categories:} Title-based heuristics mapping roles to Software, Data/AI, Design, Marketing, or Healthcare.
        \end{itemize}
    \item \textbf{Server-Side Caching:} Processed results are stored in a global \texttt{cachedInternships} variable with a 5-minute TTL (\texttt{300,000ms}) to minimize filesystem overhead.
\end{enumerate}
