\chapter{Data Collection and Preprocessing}
This chapter details the implementation of the data acquisition, sanitization, and enrichment pipeline. The system transforms raw, heterogeneous internship listings into a structured format suitable for the application's search and recommendation engines, using a series of specialized processing functions defined in the \texttt{data.ts} library.

\section{Data Ingestion Pipeline}
The system implements an asynchronous ingestion mechanism that retrieves internship data from a local repository.

\begin{itemize}
    \item \textbf{Source Acquisition:} Data is stored in \texttt{public/intern\_data.json}. The \texttt{getInternships()} function utilizes the Node.js \texttt{fs.promises} API to read the file asynchronously, ensuring non-blocking I/O operations.
    \item \textbf{Initial Validation:} Before parsing, the system performs "sanity checks" on the raw file content. It detects empty files and specifically checks if the content starts with HTML/XML tags (e.g., \texttt{<}), which often indicates an error page served by a web server instead of the intended JSON payload.
    \item \textbf{Structural Parsing:} The content is parsed into a TypeScript \texttt{Internship} interface, which defines fields including \texttt{title}, \texttt{company}, \texttt{location}, \texttt{salary}, \texttt{description}, \texttt{skills}, and \texttt{category}.
\end{itemize}

\section{Preprocessing and Sanitization}
Raw data from scrapers often contains inconsistent formatting. The system applies several sanitization layers:

\begin{itemize}
    \item \textbf{Field Normalization:} Functions like \texttt{cleanTitle}, \texttt{cleanCompany}, and \texttt{cleanLocation} strip leading/trailing whitespace and provide fallback strings (e.g., "Position Not Specified") to prevent UI breaks.
    \item \textbf{Salary Extraction:} The \texttt{cleanSalary} function uses regular expressions to extract structured currency information. It specifically targets patterns such as \texttt{\$[\textbackslash d\textbackslash .,]+[KMB]?\textbackslash s*[–-]\textbackslash s*\$[\textbackslash d\textbackslash .,]+[KMB]?} to capture both single values and ranges (e.g., "\$50K - \$70K/year").
    \item \textbf{Description Cleaning:} The \texttt{cleanDescription} function processes raw text by splitting it into lines, trimming each line, and removing empty lines. This preserves the structural intent (like bullet points) while removing unnecessary whitespace bloat.
\end{itemize}

\section{Data Enrichment and Categorization}
The system enriches the raw listings with derived metadata to improve searchability.

\subsection{Stable Identifier Generation}
To ensure persistent referencing and duplicate detection, the \texttt{generateId} function creates a URL-friendly slug. It converts the title and company name to lowercase, removes non-alphanumeric characters (via the regex \texttt{/[^a-z0-9\textbackslash s-]/g}), and replaces whitespace with hyphens. A counter-based mechanism is used during ingestion to handle collisions (e.g., \texttt{software-engineer-google-1}).

\subsection{Keyword-Based Categorization}
The \texttt{categorizeJob} function automatically assigns roles to high-level categories using keyword matching:
\begin{itemize}
    \item \textbf{Software:} Keywords: \textit{software, developer, engineer}.
    \item \textbf{Data/AI:} Keywords: \textit{data, analyst, ai, scientist}.
    \item \textit{Other categories include Design, Marketing, and Healthcare, with Business as the default fallback.}
\end{itemize}

\subsection{Skill Extraction}
The system extracts technical skills from the job description by matching text against a predefined set of keywords (e.g., \textit{JavaScript, Python, React, AWS}). The \texttt{extractSkills} function identifies these keywords in a case-insensitive manner and returns a normalized list of the top five detected skills.

\section{Performance Optimization}
To minimize overhead in the Next.js environment, the processed dataset is stored in an in-memory cache (\texttt{cachedInternships}). Subsequent calls to \texttt{getInternships()} return the cached array directly, avoiding redundant filesystem reads and re-processing of the sanitization pipeline.
