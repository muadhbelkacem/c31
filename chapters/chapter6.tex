\chapter{Data Collection and Preprocessing}
This chapter details the implementation of the data acquisition, sanitization, and enrichment pipeline. The system transforms raw, heterogeneous internship listings into a structured format suitable for the application's search and recommendation engines, following established methodologies for processing online job vacancies \cite{kurekova2015using}.

\section{Data Ingestion Pipeline}
The system implements an asynchronous ingestion mechanism designed to retrieve and validate internship data from a local JSON repository. The process of mapping diverse data sources into a unified structure is a common challenge in data integration \cite{doan2012principles}.

\begin{itemize}
    \item \textbf{Source Acquisition:} Data is persisted in \texttt{public/intern\_data.json}. The \texttt{getInternships()} function utilizes the Node.js \texttt{fs.promises} API to read the file asynchronously, ensuring non-blocking I/O operations.
    \item \textbf{Initial Validation:} Before parsing, the system performs "sanity checks" on the raw file content to ensure structural integrity, a critical step in automated data pipelines \cite{chu2016data}.
    \item \textbf{Structural Parsing:} The content is parsed into a TypeScript \texttt{Internship} interface, enforcing the schema defined in Chapter 7.
\end{itemize}

\section{Preprocessing and Sanitization}
Raw data obtained from web scrapers often contains inconsistent formatting and noise. The system applies several sanitization layers, drawing on best practices for data cleaning \cite{chu2016data, christen2012data}.

\begin{itemize}
    \item \textbf{Field Normalization:} Functions like \texttt{cleanTitle} and \texttt{cleanLocation} perform basic normalization. Data cleaning is a critical prerequisite for reliable downstream extraction and matching \cite{chu2016data}.
    \item \textbf{Salary Extraction:} The \texttt{cleanSalary} function employs regular expressions to extract structured currency information. Pattern-based extraction remains a robust baseline for highly structured attributes \cite{sarawagi2008information}.
    \item \textbf{Description Cleaning:} To maintain readability, the \texttt{cleanDescription} function removes "whitespace bloat" and redundant HTML artifacts, ensuring the text is ready for tokenization and further NLP tasks \cite{manning2008introduction}.
\end{itemize}

\section{Data Enrichment and Categorization}
The system enriches the raw listings with derived metadata to improve the user experience and searchability \cite{boselli2018classifying}.

\subsection{Stable Identifier Generation and Collision Handling}
To ensure persistent referencing and effective duplicate detection, the \texttt{generateId} function creates a URL-friendly slug. This form of deterministic blocking is essential for scaling record linkage across large datasets \cite{christen2012data, elmagarmid2007duplicate}.

\subsection{Keyword-Based Categorization}
The \texttt{categorizeJob} function automatically assigns roles to high-level categories using keyword matching. While simple, these heuristics provide a baseline for categorical filtering in large-scale recruitment analytics \cite{boselli2018classifying}.

\subsection{Skill Extraction}
The system extracts technical skills by matching text against a predefined set of keywords. This dictionary-based approach offers high precision and computational efficiency, making it ideal for the initial layer of an extraction pipeline \cite{grishman2015information, sarawagi2008information}.

\section{Performance Optimization}
To minimize I/O overhead, the system implements an in-memory caching strategy. This optimization is critical for maintaining the sub-100ms response times required for interactive applications \cite{buttcher2016information}.
